# Deltalazer Resources
The following repository is a dependency used by Deltalazer.

## Requirements
As a dependency, there are no requirements to open this repository, however some source files require specific software to edit:

### Additional Resources
* For `deltalazer-branding-guidelines.svg`: [Inkscape (Stable 1.4.2)](https://inkscape.org/release/inkscape-1.4.2/) and the [Quicksand](https://github.com/andrew-paglinawan/QuicksandFamily) font (By Andrew Paglinawan).
* For `Dissolve-Map.sifz` [Foreground and Background]: [Synfig (Stable 1.4.5)](https://www.synfig.org/)

## Notes
`delta.Game.Resources.Overrides` is intended primarily for dependency/NuGet usage. Feel free to snoop around in there, but it's highly advised that you open `deltalazer-branding-guidelines.svg` and `Dissolve-Map.sifz` instead if you want to view the designs.
